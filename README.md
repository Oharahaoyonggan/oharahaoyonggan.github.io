# Gan Yong Hao — personal website

A responsive portfolio based on the supplied resume. Open `index.html` directly or serve this directory with `python3 -m http.server 8000` and visit http://localhost:8000.

Features: a cursor-responsive animated canvas network, hover card tilt, expandable project contributions, resume download, email and LinkedIn links, mobile layouts, keyboard focus states, and reduced-motion support with a manual motion toggle.

Edit content in `index.html`, design in `style.css`, and interactions in `script.js`. Google Fonts are optional; local fallback fonts keep the site usable offline. The resume is included in `assets/`.
